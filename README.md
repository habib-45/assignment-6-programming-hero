# 🏋️‍♂️ FitLog — Workout & Fitness Tracker

FitLog is a modern, responsive web application built with Next.js (App Router) that helps users explore workout exercises, track daily fitness plans, and save favorite routines for later.

![FitLog Banner](https://raw.githubusercontent.com/habib-45/assignment-6-programming-hero/main/public/favicon.ico)

---

## 🚀 Features

- **🏋️ Detailed Workout Library:** View exercise instructions, sets, reps, duration, calories burned, and difficulty levels.
- **📅 Today's Plan Management:** Add exercises to your daily routine with dynamic calorie and time calculation.
- **🔖 Save for Later:** Bookmark exercises to easily access them in your saved collection.
- **📊 Real-time Sync:** Live navigation badges and state synchronization using LocalStorage and custom event listeners.
- **⚡ Sorting & Filtering:** Sort your plans by duration, calories burned, or ratings.
- **📱 Fully Responsive:** Optimized UI for desktop, tablet, and mobile devices built with Tailwind CSS.

---

## 🛠️ Tech Stack

- **Framework:** Next.js 16 (App Router / Turbopack)
- **Language:** TypeScript
- **Styling:** Tailwind CSS / DaisyUI
- **State Management:** React Hooks (`useState`, `useEffect`) & LocalStorage
- **Icons & Images:** Next.js Image Optimization
